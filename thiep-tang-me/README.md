# Thiệp gửi Mẹ Yêu ❤️

Thiệp online responsive, viết bằng HTML, CSS và JavaScript thuần.

## Chạy trên máy
1. Giải nén file ZIP.
2. Mở `index.html` bằng trình duyệt.

## Tùy chỉnh lời chúc
Mở `index.html`, tìm `<section class="message" id="message">` và sửa lời chúc/chữ ký.

## Thêm nhạc
Chép file MP3 bạn có quyền sử dụng vào `assets/music/`, đổi tên thành `music.mp3`. Người xem cần bấm nút **Bật nhạc** vì trình duyệt thường chặn tự phát nhạc.

## Đưa lên GitHub Pages
1. Tải `index.html`, `style.css`, `script.js`, `README.md` và thư mục `assets` lên repository.
2. Đặt `index.html` tại thư mục gốc nếu muốn trang có URL dạng `https://ten-tai-khoan.github.io/ten-repo/`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/(root)`, bấm **Save**.
5. Kiểm tra tab **Actions** và mở URL Pages sau khi triển khai xong.

## Cấu trúc
```text
thiep-tang-me/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── music/
        └── HUONG_DAN.txt
```

Không có nhạc bản quyền đi kèm. Hãy dùng file nhạc bạn có quyền sử dụng.
